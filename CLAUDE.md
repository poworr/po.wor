# po.wor

## Study every new syntax
Whenever code on this website (or any new website) uses a syntax that isn't in the study app yet
(`study/data/*.json`), add it there:
- a card in the right language file, with a short example taken from the website
- a "remember" tip (a memory hook for how to remember the syntax)
- a lesson when the syntax fits a small task

If another session owns `study/`, send it the list instead of editing it yourself.

## Every page under po.wor
Every new page gets the same header and the same footer as index.html:
the footer icons at the bottom left come from js/footer.js (load it on every page), and the footer
is hidden until you point at the bottom. Every new project or page gets a line in PROJECTS in js/footer.js.
